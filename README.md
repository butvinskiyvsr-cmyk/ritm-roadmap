# RITM — публичная дорожная карта

Здесь можно посмотреть, какие улучшения RITM изучаются, запланированы и выполняются. [Открыть доску задач](https://github.com/users/butvinskiyvsr-cmyk/projects/2).

RITM — приложение для личных и совместных задач. [Сайт](https://ritmspace.online/) · [Установщики и релизы](https://github.com/butvinskiyvsr-cmyk/ritm-releases/releases).

## Как читать доску

- **На разборе** — предложение изучается, решение ещё не принято.
- **Запланировано** — решили делать, но работа не начата.
- **В работе** — изменение разрабатывается.
- **Проверка** — изменение готово к тестированию.
- **Готово** — изменение выпущено; ссылка на релиз указана в задаче.

Публичные карточки описывают результат для пользователя. Подробные технические задачи и исходный код хранятся отдельно. Личные обращения, УИД, адреса почты, тексты писем, снимки с пользовательскими данными и секреты сюда не переносятся.

## Предложить улучшение

Пользователи RITM могут написать через **«Настройки» → «Связаться с разработчиком»** в настольном приложении. Для открытого обсуждения можно [создать предложение в Issues](https://github.com/butvinskiyvsr-cmyk/ritm-roadmap/issues/new/choose). Не публикуйте в GitHub личные данные или содержимое задач и писем.

Появление предложения в Issues не означает, что оно принято в разработку. Решение и статус появятся на доске после разбора.
